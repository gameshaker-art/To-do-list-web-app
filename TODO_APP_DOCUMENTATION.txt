OVERVIEW
================================================================================

A full-stack PHP web application for task management.

FEATURES: Add/edit/delete tasks • Categorize & prioritize • Dark mode toggle
          Sort by date/priority • Form confirmations

================================================================================
1. DATABASE
================================================================================

Database: todo | Table: tasks

COLUMNS:
  id → Auto-increment key
  task → Task description
  category → General, School, Work, Personal
  priority → Low, Medium, High
  status → 0=incomplete, 1=complete

SUMMARY: Stores task data with timestamps for creation and updates.

CONNECTION (db.php):
  Host: localhost | User: root | DB: todo | Charset: utf8mb4

3. DARK MODE TOGGLE
================================================================================

HTML (index.php):
  <button class="theme-toggle">🌙 Dark Mode</button>

JAVASCRIPT (script.js):
  document.addEventListener('DOMContentLoaded', () => {
      const isDarkMode = localStorage.getItem('darkMode') === 'true';
      if (isDarkMode) {
          document.body.classList.add('dark-mode');
      }
      themeBtn.addEventListener('click', () => {
          document.body.classList.toggle('dark-mode');
          localStorage.setItem('darkMode', isNowDark);
      });
  });

SUMMARY: 
  • Saves user preference to browser localStorage
  • Persists across page reloads
  • Clicking toggles 'dark-mode' class on body
  • CSS automatically switches all theme colors
  • Button text changes: "🌙 Dark Mode" ↔ "☀️ Light Mode"

BUTTON COLORS:
  • Check (✔):  Blue (#0066ff) → filled blue on hover
  • Edit (✏):   Orange (#f59e0b) → filled orange on hover
  • Delete (🗑): Red (#ef4444) → filled red on hover

  .actions a {

      border: 1px solid;

  }

  CONFIRMATION: "Save changes to this task?"

7. SORTING
================================================================================

HTML (index.php):
  <div class="sort">
      <a href="index.php">Default</a>
      <a href="index.php?sort=priority">Sort by Priority</a>
  </div>

BACKEND LOGIC (index.php):
  $sort = isset($_GET['sort']) ? $_GET['sort'] : 'default';

  if ($sort == 'priority') {
      $result = $conn->query("SELECT * FROM tasks ORDER BY 
          CASE 
              WHEN priority='High' THEN 1
              WHEN priority='Medium' THEN 2
              WHEN priority='Low' THEN 3
          END, id DESC");
  } else {
      $result = $conn->query("SELECT * FROM tasks ORDER BY id DESC");
  }

SORT MODES:
  • Default: ORDER BY id DESC → Newest tasks first
  • Priority: Custom CASE statement → High→Medium→Low (newest within each)

SUMMARY: Two links. Clicking adds ?sort=priority to URL. PHP reads parameter
and changes SQL query. No page reload.

10. TROUBLESHOOTING
================================================================================

ISSUE: "No database selected" error
SOLUTION: 
  - Run create_todo.sql to create the database
  - Ensure MySQL is running in XAMPP
  - Check db.php connection details match your setup

ISSUE: Dark mode not toggling
SOLUTION:
  - Clear browser cache (Ctrl+Shift+R for hard refresh)
  - Check browser console for JavaScript errors (F12)
  - Ensure script.js is loaded (check Network tab in DevTools)

ISSUE: Buttons not visible or styled incorrectly
SOLUTION:
  - Hard refresh browser (Ctrl+Shift+R)
  - Clear browser cache
  - Check style.css is loaded (Network tab)
  - Verify no conflicting CSS

ISSUE: Tasks not saving to database
SOLUTION:
  - Verify MySQL is running
  - Check database connection in db.php
  - Verify create_todo.sql was executed
  - Check for SQL errors in browser console

ISSUE: Forms not submitting
SOLUTION:
  - Check confirmation dialogs are accepting (not canceling)
  - Verify form action attributes point to correct files
  - Check PHP error logs

ISSUE: Styling looks wrong in dark mode
SOLUTION:
  - Verify CSS variables are defined in style.css
  - Check that 'dark-mode' class is being added to body
  - Hard refresh to clear cached CSS
