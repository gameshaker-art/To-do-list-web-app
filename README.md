# To-Do Application

## Description
A simple to-do list application built with PHP and MySQL.

## Setup
1. Clone the repository.
2. Create a database named `todo`.
3. Import `sql/schema.sql` to create the necessary tables.
4. Configure the database connection in the `.env` file.
5. Run the application using a local server (e.g., XAMPP).

## Usage
- Add tasks with descriptions, categories, and priorities.
- Edit or delete tasks as needed.
- Mark tasks as completed.
